# ao-db — база знаний по Albion Online

Локальная база с поиском и аналитикой по игровым данным из [ao-data/ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps)
плюс живые цены рынка из [Albion Online Data Project](https://www.albion-online-data.com/). Работает тремя способами:
**MCP-сервер** для Claude и других MCP-клиентов, **CLI** `./ao` и **Python-библиотека** `aodb`.

- 12.5k предметов со всеми зачарованиями, 30k строк рецептов, 9k спеллов, 5.5k мобов, 22k строк лута, 1.4k зон
- 40k игровых строк на 15 языках, 40k записей из всех 120 файлов дампа (полнотекстовый поиск)
- Поиск на любом языке игры, понимает префиксы тира: `8.3 палаш`, `T6 bow`
- Без зависимостей: нужны только Python ≥ 3.9 и git

## Быстрый старт
```sh
git clone https://github.com/valorouscat/ao-db && cd ao-db
./setup.sh                 # клонирует ao-bin-dumps и собирает ao.db (~15 с + время клонирования)
./ao search хранитель земли
./ao item 6.1 палаш
```
Обновить данные после патча игры: снова запустить `./setup.sh`.

## MCP
В репозитории есть `.mcp.json`, поэтому Claude Code подключает сервер `albion` автоматически, когда открыт этот проект.
Для другого проекта или клиента:
```sh
claude mcp add albion -- sh -c 'cd /path/to/ao-db && exec python3 -m aodb.mcp_server'
```
Сервер написан на stdio JSON-RPC без зависимостей, открывает базу только на чтение и возвращает компактный markdown.
Переменные окружения: `AO_DB` (путь к базе), `AO_LANG=ru` (русские названия в подписях), `AO_MCP_MAX_CHARS`.

## Инструменты
Одинаковые для MCP (`mcp__albion__<name>`) и CLI (`./ao <name>`, `./ao <name> -h`).

| инструмент | что делает |
|---|---|
| `search` | общий поиск: предметы, спеллы, мобы, зоны, игровые тексты, все сырые файлы |
| `item` | карточка: статы, item value, рецепты, апгрейд, спеллы, где используется, откуда падает |
| `variants` | все тиры и зачарования семейства предметов |
| `list_items`, `categories` | фильтр по категории, тиру, слоту, зачарованию |
| `compare` | сравнение статов |
| `recipe` | дерево крафта до сырья с учётом процента возврата ресурсов |
| `usedin`, `drops`, `loot` | обратные рецепты, источники дропа, раскрытие лут-листов |
| `mob`, `spell`, `zone` | мобы, способности (с подставленными числами), зоны |
| `loc` | любой игровой текст на 15 языках |
| `files`, `doc`, `sql`, `schema` | доступ к любым сырым данным и SQL только на чтение |
| `price`, `history`, `best_city` | живые цены, история, лучший город и флип |
| `craft_profit` | прибыль крафта: материалы с возвратом, налог станка, налоги рынка, маржа |
| `build_cost` | стоимость комплекта снаряжения по живым ценам, IP, сравнение .0–.3 |
| `gear_check` | по комплекту игрока (экспорт сборки из игры, JSON): IP по слотам, сила оружия по реальному урону выбранных умений, тип урона, набор умений и расходники; против конкретных мобов контента (все варианты шаблонов, пуллы по координатам, HP, урон автоатаки и умений, броня и сопротивления, механики для уклонения); уклонение от телеграфируемых умений 90% (и пессимистичный сценарий 50%), отдельная проверка «поймал мощный удар», защита игрока по его умениям (щиты, лечение, вампиризм, контроль, неуязвимость, кайт) — запас IP, вердикт, стоимость переодевания |
| `group_check` | прогноз для небольшой группы (2–3, до 5): роли по `itemroles.json`, суммарный урон и живучесть (танк, хил, поддержка), вердикт по тирам и стадиям, пробелы состава, лут на человека, суммарный риск |
| `chest_value` | ожидаемая ценность сундуков через таблицы лута (Авалон, коррапты, хеллгейты, мисты…) |
| `meta_builds` | статистика официального киллборда: K/D оружия, что носят игроки с этим оружием |
| `difficulty` | множители лута, серебра и славы, баффы мобов и требования IP по уровням: зачарование подземелий, комнаты боссов, цвет зоны и качество региона Запределья, мисты, Глубины, драконьи зоны, экспедиции, коррапты, хеллгейты, налоги |
| `mechanics` | официальные игровые описания контента (тексты обучения могут отставать от патчей) |
| `notes`, `save_note` | база проверенных заметок с источниками (`knowledge/`), пометка устаревших |
| `patchnotes`, `latest_patches`, `update_patchnotes` | официальные патчноуты и дев-апдейты (Steam, с 2018 года), поиск, сначала новые |
| `html` | HTML-карточки предметов с иконками |
| `info` | версия данных и статистика |

Иконки: `https://render.albiononline.com/v1/item/<ID>.png?quality=1..5&size=N`, спеллы: `.../v1/spell/<ID>.png`.

## Ответы на общие вопросы
На вопросы вроде «подбери снаряжение для проклятых подземелий» или «какие сундуки в Авалоне не стоит фармить» Claude отвечает
по протоколу из `.claude/skills/albion/SKILL.md`. Он собирает минимум три вида доказательств: игровые правила (`mechanics`),
игровые числа (`chest_value`, `mob`, `item`), реальное использование (`meta_builds`) и опыт сообщества (`notes` плюс веб-поиск).
Для любого обсуждаемого снаряжения он **всегда считает стоимость** через `build_cost`. В ответе указываются источники
и допущения, а проверенные выводы сохраняются в `knowledge/`.

## Актуальность
- **Патчноуты.** 270+ официальных постов (changelog, hotfix, dev talk) из ленты Steam хранятся в `knowledge/patchnotes/`
  и индексируются в `knowledge.db`. Источник — Steam News API: официальный сайт и форум закрыты для скриптов.
- **В карточках.** Карточки `item` и `spell` показывают «Recent patch changes» — последние изменения из патчноутов.
- **`info`.** Показывает дату дампа, текущий патч и последнее крупное обновление и предупреждает, если дамп старше патча.
- **Заметки.** Заметки, написанные до последнего крупного обновления, помечаются ⚠.
- **Хук при старте сессии.** Подтягивает новый дамп, если он вышел, и новые патчноуты.
- **Правило для ответов.** Перед ответом проверять `patchnotes` по теме: действует самый новый патч. В ответе указывается,
  для какого патча он верен.

## Примеры
```sh
./ao recipe 8.3 claymore avalon --qty 2 --return-rate 15.2
./ao craft-profit "T4 bag" --city Martlock --sell-city Caerleon --focus
./ao best-city T6_MAIN_SWORD --server west
./ao list-items --cat weapons --sub bow --tier 8 --sort ip
./ao sql "select id, name_ru, json_extract(json,'$.\"@attackdamage\"') dmg from items where sub1='dagger' and tier=8 and enchant=0"
./ao doc hellgate --keys-only
./ao chest-value avaroadloot --tier 8 --live
./ao build-cost T8_2H_BOW T8_HEAD_LEATHER_SET1 T8_ARMOR_LEATHER_SET1 T8_SHOES_LEATHER_SET1 T8_CAPEITEM_FW_MARTLOCK "10x T8_MEAL_STEW"
./ao meta-builds --weapon "T8 bow" --pages 20
./ao gear-check @my_loadout.json --content green --avg-ip 1250 --slot-ip "mainhand=1300,head=1240"
./ao group-check @examples/loadouts/bow_badon.json @examples/loadouts/mace_tank.json @examples/loadouts/holy_healer.json \
    --content blue --ips "avg=1250,mainhand=1300 | avg=1150 | avg=1150"
./ao mechanics corrupted
./ao patchnotes "roads of avalon chests"
./ao patchnotes broadsword --since 2026-01-01
```

## Устройство
```
aodb/build.py       индексатор: JSON дампа → SQLite + FTS5 (атомарная замена ao.db)
aodb/core.py        запросы к базе, каждая функция возвращает markdown
aodb/market.py      цены AODP (кэш 10 мин в ~/.cache/ao-db, мягкая обработка 429), калькулятор крафта
aodb/combat.py      урон умений и наборов оружия, урон и умения мобов (по spells.json)
aodb/gearcheck.py   оценка комплекта и группы против конкретных мобов контента
aodb/advisor.py     стоимость сборок, ценность сундуков, мета с киллборда, официальные описания, заметки
aodb/patchnotes.py  патчноуты из Steam: загрузка, конвертация BBCode→markdown, индекс, поиск
knowledge/          проверенные заметки с источниками; knowledge/patchnotes/ — официальные патчноуты
aodb/tools.py       единый реестр инструментов, из него генерируются CLI и MCP
aodb/cli.py         CLI `ao`
aodb/mcp_server.py  MCP-сервер
tests/              смоук-тесты (`python3 -m unittest discover tests`, AO_NET=1 включает тесты рынка)
scripts/session-start.sh  хук Claude Code: собирает базу в новой облачной сессии
```
Схема базы: `./ao schema`. В колонках `json` лежат исходные записи целиком (атрибуты с префиксом `@`).

## Оговорки
- Числа в описаниях спеллов — базовые значения из `spells.xml`, до масштабирования по item power.
- `chance` в loot.xml трактуется как процент (999 = гарантированно). Это интерпретация дампа, поэтому сравнение сундуков между собой надёжнее абсолютных чисел.
- Киллборд показывает только PvP-смерти (в основном открытый мир).
- Цены рынка собираются игроками и могут устаревать; смотрите колонку age. Завышенные одиночные лоты калькулятор заменяет средней ценой за 7 дней.
